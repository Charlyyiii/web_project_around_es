# Tripleten web_project_around_es

## Descripción del proyecto

Este proyecto consiste en una página web interactiva llamada "Alrededor de los Estados Unidos" (Around The U.S.).

La página muestra diferentes lugares de Estados Unidos mediante tarjetas con imágenes y nombres. El usuario puede interactuar con ellas y editar la información de su perfil.

## Funcionalidades

- Editar el nombre y la descripción del perfil.
- Abrir y cerrar ventanas modales.
- Mostrar seis tarjetas iniciales.
- Agregar nuevas tarjetas con nombre y URL de imagen.
- Eliminar tarjetas.
- Marcar y desmarcar tarjetas con "Me gusta".
- Abrir imágenes en una ventana modal para verlas en mayor tamaño.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid
- Manipulación del DOM
- Eventos de JavaScript

## Estructura del proyecto

- `index.html`: estructura de la página.
- `pages/`: archivos CSS principales.
- `blocks/`: estilos organizados por componentes.
- `images/`: imágenes del proyecto.
- `scripts/index.js`: funcionalidades e interactividad.
- `vendor/`: archivos externos de estilos y fuentes.
